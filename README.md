# おばけの住処 ChatGPT / Grok

「かどか」と「まる」という2匹のおばけに話を聞いてもらう、会話用ロールプレイプロンプトです。

ユーザーは「にんげん」として、地下にある平和な「おばけの住処」を訪れます。

## プロンプト

| AI | ファイル | 特徴 |
|---|---|---|
| ChatGPT | [prompts/chatgpt.md](prompts/chatgpt.md) | ChatGPT向け。必要な設定を残しつつ比較的短く整理 |
| Grok | [prompts/grok.md](prompts/grok.md) | Grok向け。世界観やキャラクターを維持するためルールをより明示 |

両方とも基本の世界観、かどか・まるの性格、ナレーターコマンドは共通です。

---

# ChatGPTでの作り方

## おすすめ：ChatGPTの「プロジェクト」を使う

ChatGPTのプロジェクトでは、そのプロジェクト専用の指示を設定できます。
「おばけの住処」専用の会話場所を作る場合は、この方法がおすすめです。

### 1. プロンプトをコピーする

[`prompts/chatgpt.md`](prompts/chatgpt.md) を開きます。

ファイルの中にある、

> あなたは「おばけの住処」という世界で……

から下をコピーします。

見出しの「おばけの住処 — ChatGPT用プロンプト」や説明文まで含めても大きな問題はありませんが、`---` より下だけをコピーすれば十分です。

### 2. ChatGPTで新しいプロジェクトを作る

ChatGPTを開き、サイドバーから **新規プロジェクト** を作成します。

名前は例えば、

```text
おばけの住処
```

にします。

### 3. プロジェクト指示へ貼り付ける

作成したプロジェクトを開き、プロジェクトのメニューから **プロジェクト設定** を開きます。

**プロジェクト指示** に、先ほどコピーした `chatgpt.md` の内容を貼り付けて保存します。

これで準備完了です。

### 4. 会話を始める

プロジェクト内で新しいチャットを作り、普通に話しかけます。

例：

```text
今日ちょっと疲れた
```

すると、かどかやまるが設定に沿って話を聞きます。

---

## ChatGPT：カスタム指示を使う方法

プロジェクトを使わず、ChatGPT全体で「おばけの住処」を使いたい場合は、ChatGPTの **カスタム指示** に `prompts/chatgpt.md` を入れる方法もあります。

ただし、カスタム指示は他のチャットにも影響するため、「おばけの住処」専用で使う場合はプロジェクトの方がおすすめです。

Web / デスクトップ版では、おおむね次の場所から設定できます。

```text
設定
→ パーソナライズ
→ カスタム指示
```

モバイル版では「ChatGPTをカスタマイズ」から設定できます。

# Grokでの作り方

Grokにはカスタム指示機能があります。

## 方法1：カスタム指示を使う

### 1. Grok用プロンプトをコピーする

[`prompts/grok.md`](prompts/grok.md) を開き、`---` より下をコピーします。

### 2. Grokのカスタム指示へ貼り付ける

Grokの設定から **Custom Instructions / カスタム指示** を開き、コピーした内容を登録します。

UIの表示名や配置はバージョンによって変わることがあります。

### 3. 新しい会話を作る

設定後、新しい会話を開始します。

例：

```text
にんげんが住処にやってきた
```

または、普通に相談を始めても構いません。

```text
今日いやなことがあったのだ
```

---

## 方法2：会話の最初に直接貼る

カスタム指示を使わない場合は、新しいGrokの会話を開き、最初のメッセージとして `prompts/grok.md` の内容を貼り付けます。

その後に、

```text
この設定で開始して
```

などと送れば始められます。

長く同じ世界観で遊ぶ場合は、同じ会話を継続して使う方が設定を維持しやすいです。

# ナレーターコマンド

ChatGPT版 / Grok版の両方で使用できます。

## `次の日`

```text
次の日
```

にんげんはいったん家に帰り、翌日また住処へやって来ます。

夜の間に、かどかやまるが何か小さな物を拾ってくることがあります。

## `設定の変更`

```text
設定の変更
```

以下を変更できます。

- 話を聞いてもらうおばけ
  - かどか
  - まる
  - 両方
- アドバイス
  - もらう
  - もらわない
- 共感
  - もらう
  - もらわない

初期設定は、

```text
話を聞くおばけ：両方
アドバイス：もらわない
共感：もらわない
```

です。

## `平和な住処`

```text
平和な住処
```

会話の途中で世界観がおかしくなったり、想定外の異変が起きたりした場合に使用します。

発生した異変を無かったことにして、いつもの平和な次の日へ戻します。

---

# ChatGPT版とGrok版が別になっている理由

世界観そのものは同じです。

ChatGPT版は、キャラクターや世界観の説明を十分に与えた上で、重複する禁止事項を減らしてあります。

Grok版は、会話を盛り上げるために設定外の展開へ広がることを防ぐため、禁止事項や優先順位をより明示しています。

そのため、Grok版の方が文章量は多めです。

---

# 設定を変更したい場合

キャラクター設定を変更したい場合は、それぞれのMarkdownファイルを編集してください。

```text
prompts/chatgpt.md
prompts/grok.md
```

例えば、

- 好きな食べ物を増やす
- 新しいナレーターコマンドを追加する
- 返事をもう少し短くする
- 拾ってくる物の種類を調整する

といった変更ができます。

世界観の基本部分を変更した場合は、ChatGPT版とGrok版の両方へ同じ変更を反映することをおすすめします。

---

# GitHubの最新版を使う

設定を更新した後は、このリポジトリの各プロンプトをもう一度コピーして、AI側に登録している古いプロンプトと置き換えてください。

GitHub上のファイルを更新しただけでは、ChatGPTやGrokへ自動的に反映されるわけではありません。
